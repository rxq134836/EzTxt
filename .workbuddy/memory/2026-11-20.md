## 系统毛玻璃（实验）功能实现

- 结论：本机 Win11 build 26200 + Electron 31.7.7，**无框非透明窗口 + `backgroundMaterial:'acrylic'` + `backgroundColor:'#00000000'` 可真实模糊桌面**（用彩色棋盘背板 + desktopCapturer 截屏确凿验证）。失焦/省电时系统会退化成灰底，属 Windows 官方行为。
- 关键坑：本执行环境默认带 `ELECTRON_RUN_AS_NODE=1`，`npx electron` 会变成纯 Node（表现为 `ipcMain`/`app` undefined），所有 electron 启动都要 `env -u ELECTRON_RUN_AS_NODE`；管道 `| head` 会 EPIPE 杀死 electron 主进程。dev 与已安装版共用单实例锁，测试前需先退出 `D:\GongJu\EzTxt\EzTxt.exe`。
- 实现（默认关闭，设置页「系统毛玻璃（实验）」开关）：
  - `main.js`：`sysAcrylicMode`（experimentalAcrylic && material==='acrylic' && build>=22621）；主窗口按模式以 `transparent:false + backgroundMaterial:'acrylic'` 创建；模式切换走 `recreateMainWindow()`（transparent 是创建期选项）；`saveSettings` → `applyMaterialMode()` 统一裁决。
  - mini 球拆分：该模式下主窗口隐藏，新增 56×56 独立透明窗口（`src/mini-ball.html` + `mini-ball.js`，复用 styles.css 的 `.mini-bar`/主题变量），拖拽/点击展开/鼠标穿透/打字 gif/待办计数与 legacy 一致；旧模式（opaque/translucent）仍走原单窗口缩放方案。
  - `preload.js` 新增 `onSysAcrylicState`/`onMiniShow`；`renderer.js` 用 `sysAcrylicActive` 决定 acrylic 材质保留还是回退半透明；`styles.css` 新增 `body[data-sys-acrylic="1"][data-material="acrylic"]` 规则（页面只铺 0.42 主题色，模糊交给系统）。
  - `settings.html/js`：新增开关 + 动态显示「亚克力」材质按钮；关闭开关时 acrylic 自动回退 translucent。
- 诊断脚本：`scripts/proto-acrylic.js`（交互验证）、`proto-acrylic-cfg.js`（三配置背板对比）、`proto-acrylic-shot.js`、`screen-shot.js`（desktopCapturer 截屏）。
- 遗留：mini 双窗口路径已实现并通过语法/启动冒烟，交互验证（拖球/展开/GIF/穿透）待用户手动测试；dev `data/settings.json` 已为验证改成 material=acrylic + experimentalAcrylic=true，`bgImage` 被清空（可从背景图历史恢复）。
